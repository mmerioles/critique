Download

Download

v0.1.0 · First launch: right-click, then Open.

Build from source

Needs Xcode.

git clone https://github.com/mmerioles/critique
cd critique && make install

Connect Claude Code

Run this once.

claude mcp add critique -- /Applications/Critique.app/Contents/MacOS/Critique mcp
